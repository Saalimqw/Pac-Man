**Pac-Man Upgraded** is a modern, browser-based remake of the classic Pac-Man arcade game, packaged in a single HTML file for easy use and deployment.

## Features

- Classic Pac-Man gameplay with maze navigation, dot collection, and ghost avoidance.
- Smooth animations and responsive keyboard controls for an authentic arcade feel.
- Self-contained single HTML file, no external dependencies required.

## Getting Started

1. Download or clone the repository.
2. Open `pacman-upgraded.html` in any modern web browser.
3. Use the keyboard (typically arrow keys) to control Pac-Man and start playing.

## Project Structure

- `pacman-upgraded.html` – Main game file containing HTML, CSS, and JavaScript logic.

## Usage

- Ideal for quick local gameplay, hosting on static site platforms, or embedding in portfolios and web projects.
