**Pac-Man Upgraded** is a modern, browser-based remake of the classic Pac-Man arcade game, packaged in a single HTML file for easy use and deployment.[1]

## Features

- Classic Pac-Man gameplay with maze navigation, dot collection, and ghost avoidance.[1]
- Smooth animations and responsive keyboard controls for an authentic arcade feel.[1]
- Self-contained single HTML file, no external dependencies required.[1]

## Getting Started

1. Download or clone the repository.[1]
2. Open `pacman-upgraded.html` in any modern web browser.[1]
3. Use the keyboard (typically arrow keys) to control Pac-Man and start playing.[1]

## Project Structure

- `pacman-upgraded.html` – Main game file containing HTML, CSS, and JavaScript logic.[1]

## Usage

- Ideal for quick local gameplay, hosting on static site platforms, or embedding in portfolios and web projects.[1]
